Generate `CONTRIBUTOR_GUIDE.md` for the target repository.

Audience:
A new contributor who wants to make their first useful change.

Required structure:

# Contributor Guide

## Project in simple terms
Explain the project as simply as possible.

## Local setup
Describe setup steps based on the repo. If missing, say what a contributor should look for.

## Development commands
List run/test/lint/build commands if discoverable.

## First files to read
Give a path-based reading order.

## How to make a safe first change
Suggest low-risk contribution types based on repo structure.

## How to understand failures
Explain where to look when tests, builds, or runtime commands fail.

## Coding conventions
Summarize visible conventions from the codebase.

## Pull request checklist
Give a checklist a contributor should follow before opening a PR.

## Things to avoid
Mention risky changes for new contributors.

## Missing contributor information
Mention docs or setup details that are not obvious.
